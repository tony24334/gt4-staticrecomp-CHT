# 2026-11-14

Reconstructed an experimental SCAJ-30007 ELF. The CORE declares 6,119,116
inflated bytes but yields 6,078,900 bytes and leaves an eight-byte trailer.
The script accepts only the measured CORE hash. All three ELF record bodies
were compared with their decoded source, and the USA CORE independently
reproduced the existing USA ELF hash. The CHT data zero-fill extent is provisional.

The pinned donor translator, built locally with Zig 0.15.2, emitted 324
units and reported 133,881 entries. The Windows SDL2 runner uses the donor
software GS and the CHT retail boot path. It passed a 2,700-frame scripted
boot through the no-card prompts, main menu and Arcade mode selection.
The SDL frontend initialized in a separate 60-frame dummy-driver test.

The original launcher recognizes SCAJ-30007 and prepares the pinned ELF.
The real-disc integration test and 121 desktop launcher tests passed.
Native CoreGS 2.0 presented 3,400 frames at 3x with zero renderer faults.
The portable desktop build initialized WebView2, but did not show a window
when launched from the command environment. Gameplay and save parity remain open.
